# Deployment Evidence

Add screenshots only after running the project in AWS.

Suggested evidence:
1. EC2 instance state and status checks.
2. Security group inbound rules (redact details that should not be public).
3. Apache service status and successful local HTTP response.
4. Browser showing the page served by the instance.

Do not upload AWS credentials, private keys, session tokens, or sensitive account details. Do not represent planned or simulated output as a completed AWS deployment.
